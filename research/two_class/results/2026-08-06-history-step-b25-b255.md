# Production HistoryStep B25/B255

```text
git commit      39626b22d53cf2f2c480a7e28446c197dca68043
profile         optimized bench profile, production C1 proof path
samples         3 per row except the isolated laptop B255 row
pack            authenticated two-leaf B25/B255 matrix pack
```

Each `history_step_ms` sample covers parent-terminal decoding, bounded input
preparation, recursive trace assembly, nonce sealing, proof construction and
terminal encoding. The benchmark verifies every resulting terminal as a
separate correctness gate. Verification is not included in the table time.
Transaction construction, wallet proving, block-template construction and
matrix authentication are setup. PoW search is not part of `history_step_ms`.

| Host | Class | `HistoryStep` construction | Statistic | Terminal |
|---|---|---:|---|---:|
| Low-cost AVX2 laptop, 12 threads | B25 / `m=22` | **10.734 s** | p50 of 3 samples | 971,732 B |
| Low-cost AVX2 laptop, 12 threads | B255 / `m=24` | **34.938 s** | 1 isolated sample | 1,081,108 B |
| AVX-512 PC, 24 threads | B25 / `m=22` | **6.905 s** | p50 of 3 samples | 971,732 B |
| AVX-512 PC, 24 threads | B255 / `m=24` | **21.053 s** | p50 of 3 samples | 1,081,108 B |

Run either class with:

```text
ELIDE_PACK_ROOT=../elide-artifacts/history-step-pack-v1
source "$ELIDE_PACK_ROOT/pins.env"
export ELIDE_HISTORY_STEP_PACK_DIR="$ELIDE_PACK_ROOT"

ELIDE_HISTORY_STEP_BENCH_FILTER=B25 \
ELIDE_HISTORY_STEP_BENCH_SAMPLES=3 \
cargo bench --locked -p bench_prover --bench history_step_proof

ELIDE_HISTORY_STEP_BENCH_FILTER=B255 \
ELIDE_HISTORY_STEP_BENCH_SAMPLES=3 \
cargo bench --locked -p bench_prover --bench history_step_proof
```
