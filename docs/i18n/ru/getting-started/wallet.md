# Установка и использование кошелька

Нативный пакет GUI содержит кошелёк Jetsam и его собственную полную
ноду. Приложение само запускает, контролирует и останавливает эту ноду.
Для обычной работы с кошельком терминал не нужен.

## Выбор пакета

Скачайте GUI-кошелёк для своей платформы со
[страницы релизов GitHub](https://github.com/jetsam-chain/jetsam/releases):

| Платформа | Пакет |
|---|---|
| Debian или Ubuntu, x86-64 | `jetsam-gui-vVERSION-linux-x86_64.deb` |
| Debian или Ubuntu, ARM64 | `jetsam-gui-vVERSION-linux-aarch64.deb` |
| Windows x86-64 | `jetsam-gui-vVERSION-windows-x86_64-setup.exe` |
| macOS Apple Silicon | `jetsam-gui-vVERSION-macos-aarch64.dmg` |
| macOS Intel | `jetsam-gui-vVERSION-macos-x86_64.dmg` |

Скачайте `SHA256SUMS` из того же релиза и до открытия пакета проверьте его:

```sh
# Linux
sha256sum jetsam-gui-vVERSION-linux-x86_64.deb

# macOS
shasum -a 256 jetsam-gui-vVERSION-macos-aarch64.dmg
```

В Windows используйте PowerShell:

```powershell
Get-FileHash .\jetsam-gui-vVERSION-windows-x86_64-setup.exe -Algorithm SHA256
```

Полученный хэш должен совпасть с соответствующей строкой в `SHA256SUMS`.

## Установка

### Linux

Откройте `.deb` в системном центре приложений или выполните:

```sh
sudo apt install ./jetsam-gui-vVERSION-linux-x86_64.deb
```

Запустите **Jetsam** из меню приложений.

### Windows

Запустите установщик. По умолчанию кошелёк устанавливается только для
текущего пользователя и не требует прав администратора.

Пока релизы не подписаны Authenticode, SmartScreen может предупредить о
неизвестном издателе. После проверки SHA-256 выберите **Подробнее**, затем
**Выполнить в любом случае**.

### macOS

Откройте DMG и перетащите **Jetsam** в папку Applications.

Пока релизы не нотарифицированы с Apple Developer ID, щёлкните приложение с
зажатой клавишей Control, выберите **Открыть** и подтвердите запуск. Если
macOS продолжает блокировать приложение, после проверки файла откройте
**Системные настройки → Конфиденциальность и безопасность → Всё равно
открыть**.

## Первый запуск

На первом экране есть три способа задать 256-битный мастер-секрет:

- **Создать** — сгенерировать новый случайный секрет;
- **Импортировать** — восстановить существующий секрет из 64
  шестнадцатеричных символов;
- **[Использовать фото](../wallet/photo-key.md)** — детерминированно получить
  секрет из пикселей изображения.

Перед выбором прочитайте раздел
[Первый запуск и мастер-секрет](../wallet/first-run.md). Этот секрет управляет
всеми производными адресами. Проект не сможет его восстановить.

## Синхронизация ноды

Верхняя панель показывает подключение и состояние синхронизации. Пока нода
догоняет сеть, кошелёк может отображать уже сохранённые локальные данные, но
расходуемый баланс и доступность слотов окончательны только в состоянии
**ОНЛАЙН**.

Собственная нода кошелька принимает исходящие и входящие P2P-соединения по TCP
`9700`. Для обычной работы достаточно исходящих соединений; открытый входящий
TCP `9700` также помогает связности сети.

## Получение и отправка

Активный адрес находится на главной странице. Скопируйте его кнопкой рядом и
передайте отправителю.

Чтобы отправить платёж:

1. откройте **Отправить** или нажмите `F3`;
2. вставьте корректный адрес `j1…`;
3. укажите сумму;
4. проверьте выбранные входы, выходы и сетевую комиссию;
5. нажмите **Доказать и отправить**.

Кошелёк локально создаёт доказательство авторизации с нулевым разглашением и передаёт
полную логическую транзакцию своей ноде. Финальная панель успешной отправки показывает
логический идентификатор транзакции. Статусы и подтверждение подробно описаны
в разделе [Отправка JTM](../wallet/send.md).

## Удаление приложения

Удаление программы не удаляет данные кошелька.

В Debian или Ubuntu:

```sh
sudo apt remove jetsam-gui
```

В Windows откройте **Установленные приложения → Jetsam → Удалить**. В
macOS переместите приложение из Applications в корзину.

Данные кошелька и ноды останутся в каталоге `.jetsam` профиля пользователя.
Удаляйте этот каталог только после экспорта или резервного копирования
мастер-секрета и всех чеков, которые нужно сохранить.
