# Параметры консенсуса

На этой странице собраны стартовые константы консенсуса. Если не указано иное,
значения являются целыми.

## Время и финальность

| Параметр | Значение |
|---|---:|
| Timestamp genesis mainnet | 2026-08-21 16:00:00 UTC (`1787328000`) |
| Целевой интервал блока | 180 секунд с блока 38 400 (90 секунд до него) |
| Опорная эпоха ASERT | 6 блоков |
| Период полураспада ASERT | 540 секунд |
| Окно медианы времени предыдущих блоков | 11 заголовков |
| Максимальное опережение временной метки | 120 секунд |
| Эпоха транзакций | 32 блока |
| Глубина жёсткой финальности | 8 блоков |
| Максимальная допустимая реорганизация | 8 блоков |
| Хранение недавних тел блоков | 8 блоков |
| Хранение данных отката | 16 блоков |

## Классы доказательств

| Класс | Размерность | Эффективные позиции страниц до блока 17 750 | С блока 17 750 |
|---|---:|---:|---:|
| Малый (`B25`) | 22 | 0–25 | 0–24 |
| B255 | 24 | 26–255 | 25–255 |

Основная награда исключается из эффективного числа позиций. Запланированная
выплата фондам развития занимает одну позицию.

## Доказательство работы

| Параметр | Значение |
|---|---:|
| Расписание заголовка | 16 полей `GF(2^128)`, nonce в поле 0 |
| Зерно | TowerHash (губка Poseidon2b, 8 перестановок) |
| Активация TowerWalk (публичная сеть) | блок 24 846 |
| Рабочая память TowerWalk | 65 536 × 64-битных ячеек (512 КиБ) |
| Дорожки × раунды TowerWalk | 4 × 131 072 (524 288 зависимых чтений) |
| Свёрток Poseidon2b на попытку | 33 |
| Опорная цель первого блока с обходом | `2^235` |
